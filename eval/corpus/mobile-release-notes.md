# Release Notes: Mobile App

## Version 3.2.4

Version 3.2.4 is required for all users from the first of next month, because older versions use
an authentication method that the servers will stop accepting. The app asks users to update when
it starts.

## Version 2.4.1

In version 2.4.1, receipts can be captured offline. Photos taken without a network connection are
stored on the device and uploaded automatically when the connection returns. The upload queue is
shown on the settings screen.

## Version 2.3.12

Version 2.3.12 added fingerprint login on devices that support it. Users can still sign in with
their password, and fingerprint login can be switched off in the security settings.
